# Cebimde Kur — Brand Assets

Public brand asset repository for **Cebimde Kur**.

## Brand files

Assets live under [`brand/`](./brand/).

- Primary logo: `brand/logo-primary.svg`
- App icon master: `brand/app-icon.svg`
- PNG exports for PWA / app icon use are also included.

### Brand colours

- Dark green: `#102B25`
- TRY coral: `#D55B39`
- GBP blue: `#244D91`
- Cream: `#F4EEDF`

The scan corners in the icon reference the planned camera price-recognition feature; the `₺ ↔ £` mark represents instant TRY/GBP conversion.
